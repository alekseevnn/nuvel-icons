# Nuvel Icons

Consistent line icons for modern frameworks — 1,000+ icons on one 24px grid with one line style.

Live site: https://nuvelicons.com

## Structure

This repository is the site itself: a single static `index.html` (icons, styles and scripts are inlined), plus favicons, the social preview image (`og.png`), `robots.txt`, `sitemap.xml` and Cloudflare Pages `_headers`. There is no build step.

## Deploy (Cloudflare Pages)

Connected via Git: every push to `main` redeploys automatically. Build command: *none*. Build output directory: `/`.
